# 交付前清单

逐条勾。勾不动的不要打勾，改成「不做 + 理由」。

## 立项

- [ ] `goal.md` 的每个非目标都能对应到用户明确排除的事项或已确认的范围边界。若还没有这样的决定，保留章节，写「暂无已确认的非目标」。
- [ ] 成功标准有可测的指标，不是「体验好」
- [ ] `goal.md` 写清最终可体验的效果和粗略阶段路线。README 说明当前能试什么，已有入口时写出首次操作及预期结果。
- [ ] 若用户确认了项目名或目标目录，分别核对项目名和目标项目根；不从目录名推断项目名，不把本机绝对路径写进共享文档。未确认的具体使用场景只写成示例或开放问题。
- [ ] 遇到需留存的设计或已有边界时，核对 `architecture.md` 的组件、实际代码位置、数据流和决策依据。立项阶段可暂缓创建。
- [ ] `AGENTS.md` 保留了用户已有的协作约定，路径可移植，每条可用命令有实测依据；尚无可运行入口时如实标明
- [ ] 只读成稿中的 `AGENTS.md`，能否回答四件事：哪些改动同批、提交信息怎么写、满足什么条件可直接本地提交、谁负责推送？对照 `references/templates/AGENTS.template.md` 和用户已定规则，按含义核对，不按关键词打勾。

## 里程碑

- [ ] 本期方向有依据，能指出已有办法的缺口、会改变选择的未知项及其验证时机。
- [ ] `plan.md` 只细化本期。接手者能从输入走到可观察结果，按 DoD 复验完整场景和适用反例。内部改动可独立测试、回滚和提交。
- [ ] 本期计划只有一个家：先查 `docs/plan.md`、根 `ROADMAP.md` 等已有计划；覆盖本期目标与验收条件就在原处补缺，没有才建 `docs/plan.md`。
- [ ] 风险有触发信号，不只是「可能延期」
- [ ] 有分歧时，区分哪些工作可以先做、哪项决定必须等用户取舍。

## 发版

- [ ] README 的快速开始能在干净环境复现
- [ ] `CHANGELOG.md` 与 plan 的里程碑对应
- [ ] 破坏性变更写了迁移方式
- [ ] 测试记录有放行结论和批准人

## 提交与实际验收

- [ ] 用 `git diff --cached` 核对本批逻辑范围和实际暂存内容。个人路径、设备标识、原始日志和凭据留在本地。
- [ ] 若安排独立只读审查，能指出适用授权；没有把模板视为授权，也没有让审查者修改或提交项目。
- [ ] 独立模块记录测试输入和结果。有可体验流程时，试用说明包含操作、预期和要反馈的现象。仅将用户实际验证的场景记为通过；用户暂不试用且同意提交时，状态写「已实现，待实际验证」。
- [ ] 阶段反馈逐条有去向。原定行为缺失的有修复和复验记录，新需求有后续落点，接受的限制有用户确认。涉及发布时另记放行决定。

## 文档交付或审计（纯代码改动按项目要求自测）

- [ ] 没有 `<!-- fill -->` 残留
- [ ] 没有断链（`check_docs.py` 无 WARN）
- [ ] 看过 `config` 行：用的是项目自己的配置，不是基础默认值套错了项目；`extends` 没有因为复制单文件而失效
- [ ] 看过 `scan` 行：跳过的是真的不该扫，不是漏扫
- [ ] 文档里的命令 = 清单文件里的脚本名
- [ ] 用户需要的共享文档可从 README 找到，链接目标随仓库发布
- [ ] ADR 编号唯一且递增
- [ ] 文档入库时按需用 `--staged` 检查文件范围，已核对其中的跳过提示和暂存差异
- [ ] 没有疑似凭据（`check_docs.py` 的凭据命中已逐条确认，不是靠占位符绕过）
- [ ] 整理文档时运行 `--inventory`，确认新增文件有唯一归属
- [ ] `duplicate scope` 与 `budget` 的告警已处理：合并、归档，或写明为什么保留
- [ ] 已经放进归属目录的文档在 `--inventory` 里应显示 `keep`；仍是 `review` 说明 `scopes` 缺这个允许位置，先补规则再判文件

## 存量整理（用户明确要求时才做）

- [ ] 盘点来自全量 `*.md`，不是 README 索引
- [ ] 先跑 `--inventory`，把 keep / merge / archive / review 表格交给用户
- [ ] 每份文档都归到「保留 / 合并 / 仅本地 / 删除」之一
- [ ] 每个「删除」都写明了结论去处，且引用已更新
- [ ] 归档目录没有被当成垃圾桶
- [ ] 改动前给出清单并得到确认，范围外未动

## 复盘

- [ ] 根因停在机制层，不停在「有人忘了」
- [ ] 「本该拦住它的地方」逐层填过，不是全塞给 AGENTS.md
- [ ] 至少有一条落到了自动化，而不只是文档
