# 交付前清单

## 立项

- [ ] `goal.md` 的「非目标」非空，且能挡住至少一个诱惑
- [ ] 成功标准有可测的指标，不是「体验好」
- [ ] `architecture.md` 的组件表和代码目录对得上
- [ ] `AGENTS.md` 里的每条命令都真的跑过一次

## 里程碑

- [ ] `plan.md` 只有本期范围，没有下一期的任务
- [ ] DoD 每一条都能被第三个人验证
- [ ] 风险有触发信号，不只是「可能延期」

## 发版

- [ ] README 的快速开始能在干净环境复现
- [ ] `CHANGELOG.md` 与 plan 的里程碑对应
- [ ] 破坏性变更写了迁移方式
- [ ] 测试记录有放行结论和批准人

## 任意一次交付

- [ ] 没有 `<!-- fill -->` 残留
- [ ] 没有断链（`check_docs.py` 无 WARN）
- [ ] 看过 `scan` 行：跳过的是真的不该扫，不是漏扫
- [ ] 文档里的命令 = 清单文件里的脚本名
- [ ] 新写的文档都能从 README 链到
- [ ] ADR 编号唯一且递增

## 存量整理（用户明确要求时才做）

- [ ] 盘点来自全量 `*.md`，不是 README 索引
- [ ] 每份文档都归到「保留 / 合并 / 仅本地 / 删除」之一
- [ ] 每个「删除」都写明了结论去处，且引用已更新
- [ ] 归档目录没有被当成垃圾桶
- [ ] 改动前给出清单并得到确认，范围外未动

## 复盘

- [ ] 根因停在机制层，不停在「有人忘了」
- [ ] 「本该拦住它的地方」逐层填过，不是全塞给 AGENTS.md
- [ ] 至少有一条落到了自动化，而不只是文档
